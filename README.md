# llm-tools-demo

Demo introductoria (~20 min) de herramientas para diseñar, ejecutar, guardar y evaluar
experimentos con LLMs: PyTorch, transformers, vLLM, pandas y LM Eval Harness.
Caso de estudio: *Optimal Self-Consistency for Efficient Reasoning with LLMs* (arXiv 2511.12309).

El plan completo está en [demo_herramientas_llms.md](demo_herramientas_llms.md).

| Módulo | Archivo |
| --- | --- |
| 0. Entorno | `00_check_env.py` |
| 1. Hub y datos | `01_hub_and_data.py` |
| 2. Inferencia con transformers | `02_transformers_infer.py` |
| 3. Inferencia con vLLM | `03_vllm_infer.py` |
| 4. Guardar y analizar salidas | `04_save_outputs.py` |
| 5. LM Eval Harness | `05_lm_eval.sh`, `tasks/` |

Instalación y uso: se completan en el Módulo 0.
